# Sejal - Personal Portfolio

A multi-page personal portfolio website built using semantic HTML5 with a strong focus on accessibility, SEO, and user-friendly navigation.

## 📌 About the Project

This portfolio was developed as part of Task 1 of my internship. The website follows modern semantic HTML5 standards and accessibility best practices.

## ✨ Features

- Semantic HTML5 structure
- Accessible navigation
- Skip-to-main-content link
- ARIA labels and attributes
- Logical heading hierarchy
- SEO-friendly meta titles and descriptions
- Keyboard-navigable contact form
- Accessible form labels and controls
- Multi-page website structure
- GitHub project links

## 📄 Pages

- **Home** - Introduction and areas of interest
- **About** - Education, technical skills and goals
- **Projects** - Featured projects
- **Contact** - Contact information and accessible contact form

## 🚀 Projects

### FAQ Chatbot
AI-powered FAQ chatbot developed using Python and Gradio.

### Language Translation Tool
Language translation application developed using Python and Streamlit.

### Object Detection
Computer vision project focused on detecting objects in visual data.

## 🛠️ Technologies Used

- HTML5
- Python
- Gradio
- Streamlit
- Artificial Intelligence
- Machine Learning
- Natural Language Processing
- Computer Vision
- GitHub

## ♿ Accessibility

The website was designed following accessibility best practices, including semantic landmarks, labelled navigation, logical headings, keyboard-accessible links and properly labelled form controls.
